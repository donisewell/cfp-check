## Full Description

Planner Lens surfaces FINRA BrokerCheck disclosure information directly on LetsMakeAPlan.org planner profile pages, so you can make informed decisions without leaving the page.

### How it works

When you visit a CFP® professional's profile on LetsMakeAPlan.org, Planner Lens automatically:

- Reads the planner's CRD number from the page
- Checks FINRA's public BrokerCheck database for disclosure history
- Shows a clear badge indicating whether disclosures exist
- Provides a direct link to the full BrokerCheck report

### What are disclosures?

FINRA BrokerCheck disclosures can include customer disputes, regulatory actions, criminal matters, employment terminations, and financial events like bankruptcies or liens. Not all disclosures indicate wrongdoing, but they are public information consumers should have easy access to.

### Privacy

Planner Lens does not collect, store, or transmit any user data. It makes a single API call to FINRA's public BrokerCheck service each time you view a planner profile. No analytics, no tracking, no accounts.

### Not affiliated

Planner Lens is an independent project. It is not affiliated with, endorsed by, or associated with the CFP Board, LetsMakeAPlan.org, or FINRA.
